# Reefwing Software

[Reefwing Software](https://www.reefwing.com.au/) develops software and hardware for embedded AI, robotics, IoT, flight control systems and mobile applications. We share practical tools, libraries and projects to help developers build intelligent devices.

Our repositories include Arduino libraries, sensor fusion algorithms, flight controller interfaces, embedded machine learning examples and PCB designs. Explore the code, try the examples, and contribute through issues and pull requests.

**Embedded AI: Intelligence at the Deep Edge**

Written by Reefwing Software founder David Such and published by **No Starch Press**, *Embedded AI* explains how to build, deploy and test AI on resource-constrained devices. More than 25 hands-on projects take you from sensors and data preparation to working applications, including voice detection, audio noise suppression and an AI-powered MIDI synthesizer. No prior machine learning experience is required.

📘 [Get the book from No Starch Press](https://nostarch.com/embedded-ai)  
💻 [Explore the book’s source code and resources](https://github.com/Reefwing-Software/Embedded-AI)

**Selected projects**

- [Reefwing AHRS](https://github.com/Reefwing-Software/Reefwing-AHRS) — Attitude and heading reference system for embedded applications.
- [Reefwing MSP](https://github.com/Reefwing-Software/Reefwing-MSP) — MultiWii Serial Protocol library for communicating with flight controllers.
- [NFC Business Card](https://github.com/Reefwing-Software/NFC-Business-Card) — A battery-free PCB business card with NFC and a neural-network LED animation.

Visit [reefwing.com.au](https://www.reefwing.com.au/) for development services, technical articles and project updates.
